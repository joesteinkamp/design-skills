# Ideation Methods

## How Might We lenses

| Lens | Move | Example (problem: "new users abandon setup") |
|------|------|-----------------------------------------------|
| Amplify the good | Build on what already works | HMW make the one step people enjoy the whole setup? |
| Remove the bad | Eliminate the barrier entirely | HMW let people skip setup and still get value? |
| Flip the assumption | Invert a belief the team holds | HMW make setup something people *want* to come back to? |
| Change the actor | Someone or something else does it | HMW have a teammate or the system set it up for them? |
| Change the moment | Move it earlier or later | HMW defer setup until the moment it's needed? |
| Analogy | Borrow from another domain | HMW make setup feel like unboxing a well-designed product? |

A good HMW is broad enough to allow many answers and narrow enough to know when you've answered it.

## Divergence strategies

Use these as prompts to make sure concepts differ in *strategy*, not styling.

- **Eliminate** — remove the step, field, or decision.
- **Automate** — infer, prefill, or do it in the background.
- **Defer** — ask later, progressively, or just in time.
- **Reshape content** — templates, examples, defaults, smarter empty states.
- **Change channel** — email, mobile, in-product, human (sales, support, community).
- **Social** — teammates, social proof, shared progress.
- **Incentive / model** — pricing, trial structure, rewards, commitment devices.
- **Reframe the job** — solve the upstream job so this problem disappears.

## Techniques

- **Crazy 8s** — eight rough ideas in eight minutes; quantity over quality.
- **Worst possible idea** — generate terrible ideas, then invert each.
- **SCAMPER** — Substitute, Combine, Adapt, Modify, Put to other use, Eliminate, Reverse.
- **Constraint flip** — "what if we had no engineers?", "what if it had to work by SMS?"

## Cheapest-test menu

| Assumption type | Cheapest test |
|-----------------|---------------|
| Desirability | Fake-door button, landing page, five-user concept test |
| Usability | Paper or clickable prototype, five-user task test |
| Feasibility | Engineering spike (1–2 days), Wizard-of-Oz |
| Viability | Pricing page test, sales conversation, concierge pilot |
